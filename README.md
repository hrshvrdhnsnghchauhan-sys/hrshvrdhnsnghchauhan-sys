## 🚀 SaathiX — Flagship Project

> **Solving India's ₹25 Lakh Crore MSME credit gap.**
> Most shopkeepers can't access formal credit because their sales data lives in paper diaries and cash drawers. SaathiX is a **zero-signup, voice-first** AI assistant that turns everyday business activity into a trustworthy financial record.

| | |
|---|---|
| 🎙️ **Direct-Start Voice Ledger** | Speak your sales, no typing needed |
| 📲 **1-Click WhatsApp Invoicing** | Instant, professional invoices |
| 📦 **Auto-Inventory Deduction** | Stock updates itself as you sell |
| 🤖 **AI Co-Pilot** | WhatsApp-native payment reminders |
| 📈 **Shadow Business Trust Score** | Unlocks credit access via NBFC referrals |

Built with teammates **Suraj Madheshiya** and **Kumkum Jangir** — currently building toward a **Y Combinator** application.
